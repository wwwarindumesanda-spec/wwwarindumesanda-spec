## 🚀 Projects

### 🍜 CartFinder: Street-Food Vendor Locator with Hygiene Ratings
*Mobile app | Sep - Oct 2026 

A mobile app that helps customers find street-food carts on a live map and check hygiene ratings that combine official Public Health Inspector badges with peer reviews, across customer, vendor, and inspector roles.

- Developed the cart and pre-order flow: adding menu items, adjusting quantities, choosing a pickup time, and checking out
- Built an orders tab showing pending and ready-for-pickup orders, with a navigate-to-vendor option
- Implemented QR-based pickup verification so vendors can confirm the buyer, supporting verified-buyer reviews
- Built the customer stall view and map screens
- Designed and ran functional and usability tests on the customer flows with five users

**Technologies:** React Native (Expo), Node.js, Express.js, MongoDB, Mongoose, Firebase Authentication, Redux Toolkit  
🔗 [View Repository](https://github.com/dilumiattanayake/CartFinder.git)
